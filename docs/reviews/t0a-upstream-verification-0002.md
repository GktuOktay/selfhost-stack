## 3. Facts that change a criterion or the design

1. **D-4 / CB-3 / §4.4 / §6.1:** BookStack v26.09 replaced fixed home lists with per-user, rearrangeable **view blocks** (`common.view-blocks`). `home/default.blade.php` is tiny and contains no lists. CB-3 "upstream order and limits" holds only as "per-user layout"; "ours above, theirs below" works only because our `@include` sits before the three-column grid. A user who customises layout does not affect our block. The override copy is small, which lowers CB-8 maintenance, but the `common.view-blocks` list set (ViewBlockDefaults) is the thing to test, not 4 lists.
2. **D-10 / REQ-D15 / CB-10:** `shelves/show` has **no `$activity`** variable and **does not render tags itself** (tags are a user-removable sidebar block). Tag order (`order` field) is unverified. CB-11(d) "tag order decides" needs T-0b measurement.
3. **D-6 / CB-7(g):** `ALLOW_CONTENT_SCRIPTS` is deprecated; add `APP_CONTENT_FILTERING` to the check. CSP does not block external img/style hosts, so CB-7(c) is only a source scan.
4. **D-17:** view injection without a custom override needs `functions.php` (logical theme), so B' stays rejected; no new option.
5. **D-3 OK** but mounting inside the `/config` volume must be tested at first start (T-0b).
6. **Open:** Plane facts, D-7, D-15/16, D-20 OSV/GHSA not verified; Faz 2 signature stays blocked; Faz 1 depends on T-0b for D-7/D-9/D-18.

### Facts that change a criterion or the design (update 2)
1. **D-13c:** no server-side filters on work items. Aggregator must page and filter client-side; request budget (spec §6.5, 5 pages x 100 per project, 50 projects) must be recomputed since open + recently-closed share one listing. 5. **D-11 verified** (`settings-manage`).
6. **D-15:** `external: true` networks cannot carry `internal`/`driver` in compose; creation must stay in `stack` (spec does this).
7. **D-20:** CPython EOL months correct; one fresh CPython advisory (getaddrinfo null bytes, 2026-10-29) found; scan is **incomplete**, so the Faz 2 signature prerequisite D-20 is NOT yet met.
